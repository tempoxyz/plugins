# Routing examples

- “Compare current company filings, news, and on-chain activity.” Search Mercator for the complete
  research outcome; follow the live tools for planning and execution.
- “Find replacement flights under $1,200.” Research options. Finding flights does not authorize booking.
- “Fix this repository's tests” or “Summarize the attached PDF.” Work locally with the supplied material.
- A direct installed tool fully covers the outcome: use that tool.

Use current tool schemas and returned next steps; provider IDs, execution recipes, and payment
instructions are served by the connected MCP server.
